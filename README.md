# Assistente VIP - Mercado Central 24h
Chatbot corporativo utilizando RAG (Retrieval-Augmented Generation) com LangChain, ChromaDB e Gemini 3.6-Flash.

## Como executar
1. Instale as dependências: `py -m pip install -r requirements.txt`
2. Insira sua `GOOGLE_API_KEY` no arquivo `.env`
3. Inicie a interface: `py -m streamlit run interface.py`
